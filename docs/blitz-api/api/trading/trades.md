> This section covers the **raw REST API** using curl examples.
> For SDK usage examples with BlitzConnect, see [BlitzConnect Trades](../../sdk/blitzconnect-api/trades.md).

!!! tip "**Using CorrelationOrderId**"
    Pass your own `CorrelationOrderId` when placing orders — it helps you reconcile trades and match them back to your system's records.

!!! note "**What is `blitzOrderId`?**"
    The `blitzOrderId` is the unique, system-assigned numeric identifier of an order (e.g. `222115050150000049`), returned when you place the order. One order keeps the same `blitzOrderId` for life — even after modifications, partial fills, or cancellation — and every fill for that order stays linked to it. Use it with `trades/{blitzOrderId}` to fetch all fill events for that specific order.

!!! note "**Recent Data Only**"
    The Trades API returns trades from the current trading session. For historical data across multiple sessions, refer to the Statistics API or your own trade logs.

# Trades API

The **Trades API** allows users to retrieve historical trade and transaction data for orders executed through the platform. These endpoints support use cases such as reviewing trading activity, analyzing performance, generating reports, and maintaining records for compliance and auditing.

```
BASE URL : https://{baseurl}/api_interactive/api/v1
```

| **Type** | **Endpoint**                                   | **Description**                               |
| -------- | ---------------------------------------------- | --------------------------------------------- |
| GET      | [trades](#fetching-trades)                     | Retrieve the list of all trades.              |
| GET      | [trades/{blitzOrderId}](#fetch-trades-by-id)   | Retrieve trades for a specific order (by `blitzOrderId`). |

# Fetch Trades {#fetching-trades}

Retrieve all trades currently recorded for a given client, entity, or strategy instance.

```bash
curl -X 'GET' \
  'https://{baseurl}/api_interactive/api/v1/trades' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer {access_token}'
```

# Fetch Trades by BlitzOrderId {#fetch-trades-by-id}

Retrieve all trade (fill) events recorded for a specific order, identified by its `blitzOrderId`.

```bash
curl -X 'GET' \
  'https://{baseurl}/api_interactive/api/v1/trades/217105131760000028' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer {access_token}'
```

## Response Structure

The endpoint returns an **array** of trade records for the requested `blitzOrderId`. Each entry has the exact same shape as a trade from [Fetch Trades](#fetching-trades) above. When no fills are recorded for the given `blitzOrderId` in the current session, the endpoint returns `404`:

<details>
<summary>Click to view 404 JSON Body</summary>

```json
{
  "message": "No trades found for BlitzOrderId 217105131760000028."
}
```
</details>
