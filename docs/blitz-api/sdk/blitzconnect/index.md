# BlitzConnect SDK

Python and C# client libraries for the [BlitzConnect API](../blitzconnect-api/index.md) — build algorithmic trading applications, stream live market data, and manage portfolios.

A Software Development Kit (SDK) is a collection of libraries, tools, and pre-built components that simplifies integration with the Blitz API. It enables developers to interact with trading and market data services through intuitive functions and methods, eliminating the need to manually construct HTTP requests, manage authentication headers, or parse API responses.

## Why use the SDK?

- **Simplified Integration** — No need to manually construct API requests or handle low-level details.
- **Built-in Authentication** — Automatically manages tokens and headers.
- **Error Handling** — Standardized error handling across all API calls.
- **Type Safety** — Strongly typed models for request and response data.
- **Pre-built Methods** — Ready-to-use functions for placing orders, fetching positions, and more.
